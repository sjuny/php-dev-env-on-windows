# 処理記録スキル

## 1. 処理目的

- 処理を指示したチャットの内容と変更したファイル内容から処理記録を作成し、ファイルへ出力する。

## 2. 処理順序

**必ず**、以下の処理を項番にごとに、一つずつ、まとめずに実行する。

- 1. ログファイルパス作成スクリプトからログファイルパスを取得する。
  - スクリプトは、AGENTS.mdに記載された処理OSに応じて以下のいずれかを選択して実行する。
    - Windows：`<skill-directory-path>/scripts/create-log-file-path.ps1`
    - Linux：`<skill-directory-path>/scripts/create-log-file-path.sh`

  - パスは標準出力に表示されるのでそれを取得する。

- 2. gitリポジトリに未コミットのファイルと変更行数を特定する。
  - 変更ファイルや内容がなければ次の処理へ移る。

- 3. このスキルを実行したチャット内容と項番2の内容を元に、ログのテンプレートファイルに従い処理記録を出力する。
  - テンプレートファイルは以下。
    - `<skill-directory-path>/references/log-template.md`

  - 項番1で取得したパスに内容を出力する。

  - ログの記録内容は後述の「処理記録の内容」に従う。

## 3. 処理記録の内容

- 指示内容。
- 実装計画ファイルがあればその処理内容ごとに、以下を記載する。
  - 処理対象のファイルや行数。
  - 処理の概要。
  - 処理時に問題があればその原因と対処方法。
