# プログラミングスキル

## 1. 処理目的

- プログラムの仕様を取得し、コード生成スキルを利用してプログラムコードを生成する。

## 2. 処理順序

以下の項番ごとの処理を、**絶対に** まとめて実行せず、一つずつ実行する。

- 1. コード生成の元となる仕様、または、指示の取得方法の選択肢をID付きで提示して、ユーザーに選択させる。
  - a.gitにより変更ファイルと差分情報を抽出する。
  - b.チャットのメッセージ。
  - c.IDE拡張が検知した選択ファイル。

- 2. 項番1で選択した仕様や指示の取得方法に従い、以下の異なる処理を実行する。
  - 2-1. 項番1で「b.gitにより変更ファイルと差分情報を抽出する。」を選択した場合。
    - gitコマンドで未コミットの変更ファイルと変更箇所を取得する。

  - 2-2. 項番1で「b.チャットのメッセージ」を選択した場合、ユーザーにチャットに仕様を入力するように促し、ユーザーが入力したらそれを仕様とする。

  - 2-3. 項番1で「c.IDE拡張が検知した選択ファイル。」を選択した場合、IDEが検知している選択済みのファイルの内容を読み込み仕様や指示を取得する。

  - 上記のいずれにおいても、参照、および、参照するファイルは、以下のディレクトリ配下のみ。
    - `<project-root-directory-path>/.tasks`
    - `<project-root-directory-path>/docs`

- 3. 項番2で取得した仕様、および、既存コードやdocs内の資料を元に、コードの作成や修正の計画書をタスクディレクトリに出力する。
  - 計画書のファイル名は、「yyymmddHHmm_plan.md」にする。
  - 計画書の内容は以下。
    - 作成や修正対象のコードファイル、および、ファイル別の編集内容。
    - 修正による問題と対応策。

- 4. 計画書に従ってコードを実装してよいか、ユーザーに実行の確認をする。
  - yの場合、次の処理を実行する。
  - y以外の場合、計画書の内容の修正点を質問して、計画書を修正する。その後、再度、実装を確認する。

- 5. 計画書に従い、コード生成スキルを利用してコードを実装する。
  - コード生成をする場合、**必ず**、以下のソースファイルの拡張子に対応したコード生成スキルを利用する。
    - .ps1、.psd1、.psm1：$powershell-coding
  - **絶対に** 異なるプログラム言語のスキルを使わない。
  - 生成したプログラムコードの実行確認は**絶対に**しない。
