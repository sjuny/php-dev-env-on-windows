# 処理ログ出力付きブランチマージスキル

## 1. 処理目的

- 処理ログを作成してからブランチをーマージする。

## 2. 処理順序

以下の項番ごとの処理を、**絶対に** まとめて実行せず、一つずつ実行する。

- 1. $process-logging スキルを実行して、処理ログを現在のタスクディレクトリに処理ログを出力する。

- 2. 未コミットのファイルをすべてステージングして、コミットする。
  - コミットメッセージは、コミットしたファイル内容を要約して作成する。

- 3. 現在のブランチをマージする先のブランチ名をユーザー選択させる。
  - ローカルのブランチ名を番号付きで表示して、ユーザーに番号を入力させる。

- 4. 以下のコマンドを実行して、現在のブランチを項番2で選択したマージ先ブランチにマージする。
  - コマンドは、`<skill-directory-path>/scripts/git-merge-current-branch.ps1`

```shell
# powershell
git-merge-current-branch.ps1 -TargetBranch <マージ先ブランチ>
```
