# gitのmainブランチマージ処理

## 処理目的

- 現在チェックアウト済みのブランチを指定ブランチにマージする。

## 技術スタック

- プログラム言語：PowerShellv5.1

## パラメーター

- マージ先ブランチ名
  - 任意
- マージメッセージ
  - 任意

## 処理順序

- 1. 未コミットがある場合は、マージせずエラーメッセージを表示して中断する。

- 2. マージ先のブランチを決定する。
  - パラメーターの「マージ先ブランチ名」がある場合は、パラメーターの値をマージ先とする。
  - パラメーターの値がない場合は、ローカルブランチ名を番号付きで表示し、ユーザーに番号で選択させる。
    - 選択した番号のブランチをマージ先とする。

- 3. 項番1で決定したマージ先のブランチに、現在のブランチをマージする。
  - パラメーターのマージメッセージがあればそれをメッセージに設定する。

- 4. マージ済みの現在のブランチを削除して、マージ先のブランチをリモートリポジトリにpushする。

## 処理補足

### SSH接続

- 日本語を含むユーザープロファイルのパスによるGit for Windows内蔵SSHの問題を回避するため、Windows標準OpenSSHを使用する。
- Windows標準OpenSSHが存在する場合は、`GIT_SSH_COMMAND`へ実行ファイルのパスを設定する。

### リモートGitコマンドのエラー処理

- `git fetch`、`git pull`、`git push`の実行時は、SSHの警告やGitの進捗メッセージがPowerShellのエラーとして扱われないようstderrを抑制する。
- リモートGitコマンドの実行中は`ErrorActionPreference`を一時的に`Continue`へ変更し、処理後に`Stop`へ戻す。
- リモートGitコマンドの成否は、PowerShellの例外ではなく`LASTEXITCODE`で判定する。
- ホストキー検証失敗、SSHの秘密鍵読み込み失敗、リモートGitコマンドの実行失敗をエラーとして扱う。
