# タスクディレクトリ作成スクリプト

## 処理概要

- タスク用のgitブランチとディレクトリを作成する。

## スクリプトパラメーター

引数を、「パラメーター名・内容：データ型」の形式で記載する。

- タスクID：文字列

## 処理順序

- 1. ブランチ名の「/」の前半の種別名をユーザーに番号で選択させる。
  - 以下の選択肢を番号付きで表示する。
    - 1.新規機能追加：feature
    - 2.不具合修正：fix
    - 3.仕様変更：change
    - 4.調査：research
    - 5.その他：other

- 2. スクリプトパラメーターのタスクIDと項番1の種別名を結合してgitのブランチ名を作成する。
  - ブランチ名は「種別名/タスクID」。後述の「ブランチ名作成例」を参考にして作成する。
  - IDは小文字化し、英数字・ハイフン以外の文字はハイフンに置換する。
  - 先頭・末尾のハイフンは除去する。

- 3. 項番2で作成した名前でブランチを作成する。

- 4. `.tasks`ディレクトリ内に以下のタイムスタンプ付きの形式でディレクトリを作成する。
  - このディレクトリをタスクディレクトリと呼ぶ。
  - ディレクトリ名：`yyyymmdd-hhmm_タスクID`

- 5. 項番4で作成したタスクディレクトリ内に、「instr-01.md」という空ファイルを作成する。

- 6. 全ての処理が成功したら、以下のメッセージを出して、成功のステータスコードを呼び出し元に返却する。
  - `タスク用のブランチとディレクトリが作成されました。/ branch=<ブランチ名> , directory=<ディレクトリ名>`

## ブランチ名作成例

- 入力値
  - 指示の種類：fix
  - 指示内容ID：menber-screen-entry-bug

- ブランチ名
  - fix/menber-screen-entry-bug
